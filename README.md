# 🚀 Dark File Converter Pro

100% free, open-source, and unlimited desktop file converter built with Python and PySide6.

## ✨ Why this app?
Most online file converters push subscriptions, show intrusive ads, or restrict file sizes. This tool runs **entirely locally on your PC** — no paywalls, no limits, and complete privacy for your files.

## 🛠 Features
* **Images:** PNG, JPG, WEBP, BMP, ICO, TIFF, GIF, TGA
* **Media:** MP3, WAV, OGG, FLAC, AAC, M4A, MP4, AVI, MKV, WEBM, WMV, FLV
* **Documents:** PDF, TXT, MD, HTML, DOCX, EPUB, FB2
* **Data:** CSV, XLSX, JSON, XML, PARQUET, HTML
* **Archives:** ZIP, TAR, GZ, 7Z
